# 火災調査書類作成支援（試作版）

標準火災調査書類作成マニュアル（総務省消防庁、令和4年8月）に沿って、火災調査書類（様式1〜9）の作成を支援するウェブアプリの試作版です。

- アプリ：https://is1g60th-beep.github.io/Kasai-app/
- このリポジトリは公開用で、アプリのファイル（`index.html`）だけを置いています。開発は非公開のリポジトリで行っています。

## 使う前に

- **試用は架空のデータだけで行ってください。**
- 入力したデータは、開いた端末のブラウザの中（IndexedDB）にだけ保存されます。外部へは送信しません。他の端末とは共有されません。
- ブラウザのデータを消すと、入力したデータも消えます。「バックアップ」画面から定期的に書き出してください。
- 火災原因はアプリが決めるものではありません。最終的な判断は調査担当者が行います。
